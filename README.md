# Two-minute pupil test

A browser test for a research pilot: it checks whether pupil size can be measured with
an ordinary webcam, using the pupil's automatic response to screen brightness.

Open the page, read the instructions, press Begin. The camera is used only while the
test runs and nothing is uploaded — at the end you download a small results file and
send it back to whoever gave you the link.
